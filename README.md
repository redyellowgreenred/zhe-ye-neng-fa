# 这也能发？

只看三句话，猜一篇论文发在顶会／顶刊，还是普通期刊。

- 单人猜题，或双人同屏轮流作答，双方锁定后一起揭晓。
- 每局 10 题，每题 10 分。
- 13 个领域各 100 篇，共 1300 篇真实论文，保留原始出处。
- 手机、电脑都能玩，加载后支持离线，也可下载单文件版。

顶会／顶刊是这份题库预先选定的发表场所分组，不代表统一排名或每篇论文的质量。摘要根据公开摘要选句、翻译和改写；部分专业表述仍需持续复核。

这是无需构建的静态网页。GitHub Pages 发布源设为 `main` 分支的根目录即可。
