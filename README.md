# 这也能发？

只看三句话，猜一篇论文发在顶会／顶刊，还是普通期刊。

**直接玩：https://redyellowgreenred.github.io/zhe-ye-neng-fa/**

- 单人猜题，或双人同屏轮流作答，双方锁定后一起揭晓。
- 好友联机：房主选领域、创建房间，把邀请链接发给好友；两人各用自己的设备作答，同步揭晓和计分。
- 每局 10 题，每题 10 分。
- 音效可开关；本机生涯榜记录完整对局胜场和累计正确率。
- 覆盖 13 个领域，共 2200 篇真实论文，保留原始出处。
- 手机、电脑都能玩，加载后支持离线，也可下载单文件版。

顶会／顶刊是这份题库预先选定的发表场所分组，不代表统一排名或每篇论文的质量。原有1300篇已全部对照原摘要重写，累计新增900篇。最近增加的200篇全部来自心理学（68）、社会科学（66）和经济学（66）。三句话依次讲研究问题、具体做法和主要发现，必要术语配解释，保留无效结果和研究限制。

这是无需构建的静态网页。GitHub Pages 发布源设为 `main` 分支的根目录即可。

## 联机

房间最多两人，第三位加入时明确显示「房间已满」；原玩家刷新重连不会被当成第三人。双方锁定后，任意一人都可以确认揭晓；双方都准备好才进入下一题。支持整局复盘、双方同意后再比一局、断线重连。创建房间后可点「分享给好友」发送邀请；暂时切到聊天软件、返回或刷新时自动恢复原房间。页面被回收后可点「回到上次的房间」，本地备份保留24小时。房主彻底关闭浏览器期间，好友仍需等房主回来。

联机使用 PeerJS 1.5.5 的免费信令服务和 WebRTC 加密数据连接；Cloudflare 与 Google STUN 用于发现网络地址。选择先发送带随机盐的 SHA-256 承诺值，双方锁定并确认后才交换实际选择。题库本身公开，适合朋友间娱乐，不作为防作弊竞技系统。

没有部署自己的 TURN 中继服务。对称 NAT 或限制 WebRTC 的公司、校园网络可能无法直连，界面会提示换网络或重试。双端十题、刷新恢复、成绩一致与再来一局已实测；尚未覆盖所有手机运营商和路由器组合。

单人和同屏双人保持离线可用；好友联机需要网络。联机组件仅在创建或加入房间时加载。PeerJS 许可见 `PEERJS-LICENSE.txt`。

标题字体为站酷快乐体，采用 SIL Open Font License，见 `FONT-LICENSE.txt`。

联机支持本局题目同步，两人本地题库不同也能同题作答；首次更新旧版联机程序仍需双方刷新一次。生涯榜按胜场、正确率排序，平局不计胜场，单人只累积正确率；战绩保存在本设备浏览器，相同昵称合并，暂不跨设备共享。
